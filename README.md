# CLI Logger Gateway

Многопоточное консольное приложение и динамическая библиотека на C++17 для асинхронного логирования текстовых сообщений. 

Проект разработан для потокобезопасной записи сообщений в журнал (текстовый файл) с поддержкой различных уровней важности. Взаимодействие с библиотекой осуществляется через CLI-интерфейс, который выносит процесс записи на фоновый поток, предотвращая блокировку основного приложения.

## Особенности архитектуры
* **Динамическая загрузка библиотеки**: Динамическая библиотека загружается в рантайме с использованием POSIX-функций `dlopen`/`dlsym`.
* **Асинхронность**: Основной поток приложения отвечает исключительно за чтение пользовательского ввода. Сообщения складываются в потокобезопасную очередь и обрабатываются фоновым потоком.

## Требования
* ОС: `Ubuntu / Debian` (POSIX-совместимая среда)
* Компилятор: `GCC` с поддержкой `C++17`
* Утилиты: `make`

## Сборка проекта

Используется Makefile для удобного управления процессом сборки.

1. **Собрать всё (библиотеку и приложение):**
   ```bash
   make all
   ```
2. **Запустить тесты (модульное тестирование парсера команд):**
   ```bash
   make test
   ```
3. **Очистить директорию от бинарных файлов (clean):**
   ```bash
   make clean
   ```
Скомпилированные файлы появятся в директории `bin/`.

## Использование

Для запуска приложения необходимо передать два обязательных аргумента: путь к файлу журнала и уровень важности по умолчанию (LOW, MEDIUM, HIGH).
```bash
./bin/journal_app <путь_к_файлу> <уровень_важности>
```

Пример запуска:
```bash
./bin/journal_app app_logs.txt MEDIUM
```

### Команды CLI (Интерфейс)

После запуска приложения вы попадете в интерактивную консоль `>`. Поддерживаются следующие команды:

* `help` - Вывести список доступных команд.
* `exit` - Завершить работу приложения.
* `log` - Вывести всё содержимое текущего журнала в консоль.
* `jnl -gl` - Вывести текущую важность по умолчанию.
* `jnl -sl <level>` - Изменить важность по умолчанию на указанный уровень.
* `msg [level] <text>` - Сохранить сообщение в журнал с указанным уровнем важности. Если уровень не указан, используется настройка по умолчанию. Текст можно оборачивать в кавычки.
* `<text>` - Любой ввод, не являющийся командой, интерпретируется как сообщение с уровнем важности по умолчанию.
